## How-to — 動かし方

データを取得する（リポジトリには含めていない）。

```sh
uv run kaggle competitions download -c <コンペ名> -p data/
unzip data/<コンペ名>.zip -d data/
```

実行する。

```sh
uv sync
uv run pytest              # 検査
uv run jupyter lab         # ノートブックを開く
```
